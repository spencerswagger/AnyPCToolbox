🧰 AnyPCToolbox — 架构设计

Tauri 2.x + Vite + Vue3 + shadcn/ui · 一套代码覆盖桌面端和 Web

系统架构

🖥️ 桌面端 (Tauri)

Rust 后端 (src-tauri/)
文件系统 · 系统 API · 原生窗口管理
⬇ 系统 WebView 渲染
WebView (macOS: WKWebView / Win: WebView2 / Linux: WebKitGTK)
操作系统原生 WebView，不捆绑 Chromium
⬇ 渲染 HTML/CSS
Vue3 前端 (Vite 构建产物)
shadcn/ui · 离线运行 · 本地依赖

🌐 Web 端

Vite 构建产物 (纯静态文件)
部署到任何静态文件服务器
⬇ 浏览器渲染
Vue3 前端 (同一套代码)
shadcn/ui · 完整功能可用

项目结构
