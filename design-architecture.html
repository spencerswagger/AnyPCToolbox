技术栈对比：之前 vs 现在

维度 之前 (Tauri + Rust) 现在 (纯前端) ✅
Rust 后端 需安装 Rust 工具链，跨平台编译 ✓ 完全不需要
构建工具链 npm + Cargo 两套构建 ✓ 仅 npm，单命令构建
桌面端运行 依赖系统 WebView 版本 ✓ 浏览器打开即可，或用 PWA
Web 端部署 Vite 构建产物直接部署 ✓ 完全一样
代码复用 ✓ 一套前端代码 ✓ 一套前端代码
安装包体积 几 MB (Tauri 壳 + 前端) ✓ 纯前端，体积更小
