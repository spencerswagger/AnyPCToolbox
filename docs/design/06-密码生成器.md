# 产品方案：密码生成器（indexedDB 本地持久化）

> 状态：设计稿（未实现） · 日期：2026-08-22 · 模式：纯前端本地（Tauri 优先）

## 一、定位

标准随机密码生成器 + **纯本地密码管理**。生成结果与已保存的账号/密码条目通过 **indexedDB** 本地持久化，彻底离线，不依赖任何后端。

## 二、目标用户

- 需要生成强随机密码、且希望密码记录"只存本机、不上云"的个人用户。
- 轻度密码管理（不想上重量级密码管理器）的普通用户。

## 三、页面布局

```
┌─────────────────────────────────────────────────────────────┐
│ ← 返回 | 密码生成器                    [新增条目]              │
├─────────────────────────────────────────────────────────────┤
│  生成区                                                       │
│  长度[16] 字符集: [大写][小写][数字][符号][去易混淆](复选)        │
│  强度条 █████░      [生成] [复制]                               │
├─────────────────────────────────────────────────────────────┤
│  已保存密码列表（管理区）                                      │
│   [应用] [账号] [密码(●●●●)] [备注] [复制][编辑][删除]           │
│   添加入口：应用名/账号/密码/备注 → 保存                        │
├─────────────────────────────────────────────────────────────┤
│  (折叠) 高级：启用本地加密（主口令 + AES-GCM 加密后落库）         │
└─────────────────────────────────────────────────────────────┘
```

- 生成区与已保存列表上下分区；保存列表为空时显示空态占位。
- 强度通过熵估算给出指示条与文案（弱/中/强）。

## 四、交互流程

1. 调参 → `生成` → 复制。密码可用 `crypto.getRandomValues` 保证随机性。
2. "保存到列表"把当前生成的密码填入新增条目表单，补应用名/账号/备注后保存。
3. 列表增删改、复制、导出（导出为本地 `.json`/`.csv` 备份）。
4. 可折叠的"启用本地加密"高阶项：设置主口令后，用 WebCrypto AES-GCM 加密落库，读时输入主口令解密。

## 五、功能详述

- **字符集**：大写/小写/数字/符号/去易混淆（`0OIl1` 等）/ 自定义字符集。
- **随机源**：`crypto.getRandomValues`（非 Math.random），保证密码质量。
- **强度**：按池大小 + 长度计算熵（bits）并分级。
- **持久化（indexedDB）**：条目含 `{ id, app, account, password, note, createdAt, updatedAt }`。
- **进阶加密（折叠）**：主口令 + 随机 IV，AES-GCM 加密 password 与整个条目；未启用时明文存储并明示"未加密，仅本机保存"。

## 六、数据与状态

- 数据库：`indexedDB`，库名 `anypctoolbox`，表 `passwordEntries`。
- 偏好（默认长度/字符集勾选）存 localStorage（key: `pwdgen:prefs`）。
- 主口令不上传、不存明文；仅用于派生密钥（PBKDF2）。

## 七、技术要点与模块划分

```
src/lib/password/
  generate.ts    # 随机密码生成纯函数（池+长度+去易混淆）
  entropy.ts     # 熵估算 + 强度分级
  store.ts       # indexedDB 封装（增删改查）
  encrypt.ts     # AES-GCM + PBKDF2 加密/解密（可选开启）
src/views/PasswordGen.vue
```

- store 层可复用给后续需要 indexedDB 的工具（见 #07 动态令牌共用加密存储）。

## 八、边界情况

- 长度输入非法：钳制到 [1, 256]。
- 勾选冲突（如所有字符集取消）：至少保留大写 + 数字兜底，提示。
- 明文存储模式：界面明示"未启用加密"，避免误导。
- 主口令错误解密失败：提示"口令错误"，不清数据。
- 导出/导入备份：本地文件，便于迁移；导入时校验结构。

## 九、不做的事

- 不做云端同步 / 网络同步。
- 不做浏览器自动填充 / 自动保存（仅手动列表）。
- 不做密码强度破解式评估（仅熵分级）。
- 不做 TOTP（见 #07 独立工具）。
