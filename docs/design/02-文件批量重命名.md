# 产品方案：文件批量重命名

> 状态：设计稿（未实现） · 日期：2026-08-22 · 模式：纯前端离线（Tauri 桌面态优先）

## 一、定位

用**可视化规则块 + 实时预览**替代传统工具的"模板语法"，把高上手门槛的文件批量重命名工具给降下来。用户无需记忆 `%n%`、`{seq}` 之类的占位符，所见即所得。

参考对标：`https://z.tools/zh/t/file-rename`（其模板语法难上手，本设计用图形化规则 + 逐行对照预览化解此痛点）。

## 二、目标用户

- 整理照片/文档/下载目录的普通用户。
- 需要批量规范化文件名的运营、编辑、开发者。

## 三、页面布局

```
┌─────────────────────────────────────────────────────────────┐
│ ← 返回 | 文件批量重命名            [选择文件][拖拽区域]       │
├─────────────────────────────────────────────────────────────┤
│ 文件区：已选文件列表（原名 · 大小 · 类型，可移除）             │
├─────────────────────────────────────────────────────────────┤
│ 规则区：可增删排序的规则块                                   │
│   [查找-替换][前缀/后缀][序号][时间戳][大小写][删字符][扩展名] │
├─────────────────────────────────────────────────────────────┤
│ 预览区：逐行对照 原名 → 新名，差异高亮（增绿删红），可勾选跳过 │
│  · 冲突项红标提示                                           │
├─────────────────────────────────────────────────────────────┤
│                        [应用更改]  底栏：共 N · 将改 M · 冲突 K │
└─────────────────────────────────────────────────────────────┘
```

- 自上而下的单一纵向流，规则按从上到下顺序依次作用。
- 桌面（Tauri）态支持拖拽文件/文件夹；Web 态退化为多选文件。

## 四、交互流程

1. 选择/拖入文件 → 文件区列出。
2. 点击"添加规则"，从七种规则类型中选择一项，展开该类型参数表单。
3. 每改一个参数，预览区**即时**重算，逐行显示"原名 → 新名"及差异高亮；不满足条件（如替换项未命中）的行保持原名并灰显。
4. 用户可逐行取消勾选（跳过某文件）；冲突（生成同名）行红标，结尾的冲突处理（自动加序号）可选开启。
5. 点 `应用更改` 执行，Tauri 态真正改盘上文件名；执行后进入历史可撤销。Web 态仅提供重命名后的文件名列表下载（浏览器无法改本地路径）。

## 五、规则类型（图形化参数，非模板语法）

| 规则 | 参数 | 示例 |
|---|---|---|
| 查找-替换 | 查找串、替换串、是否仅首个 | `IMG_` → `Photo_` |
| 前缀 / 后缀 | 添加的文本 | `2025-` / `_final` |
| 序号 | 起始、步长、位数、位置（前/后）、分隔符 | 前加 `01_ 02_ ...` |
| 时间戳 | 格式模板（选择而非自由输入）、来源（当前时间/文件修改时间） | `20260822_` |
| 大小写 | 全大写 / 全小写 / 首字母大写 | `IMG_001` → `img_001` |
| 删除字符 | 从第几位删 N 位 / 删除指定字符集 | 去前 4 位 |
| 扩展名 | 统一替换扩展名 / 保留 | `.jpg` |

- **正则**作为"高级"折叠选项保留在"查找-替换"与"删除字符"内，默认收起，避免吓退普通用户。

## 六、数据与状态

- 无需持久化文件本身；重命名**操作历史**存 localStorage（key: `rename:history`），供撤销。
- Tauri 态通过后端命令执行文件写操作与读取元信息（修改时间）。

## 七、技术要点与模块划分

```
src/lib/rename/
  build.ts        # buildName(name, rules) 纯函数：单个文件名 -> 新名
  preview.ts      # batchPreview(files, rules) -> [{old,new,changed,conflict}]
  conflict.ts     # 冲突检测 + 自动补序
  history.ts      # 撤销操作栈（localStorage）
src/views/Rename.vue
src/components/rename/RuleBlock.vue  # 七种规则各自的参数表单
```

- **核心是可测纯函数 `buildName`**：改名逻辑与 UI 完全解耦，预览、执行、单测共用同一函数，天然一致的展示与结果。

## 八、边界情况

- 中文、空格、emoji、特殊字符文件名：正确保留与高亮（不破坏 Unicode）。
- 空文件名 / 全空白名：拒绝。
- 目标名超长 / 含非法字符（`\/:*?"<>|`）：标红并禁用应用。
- 同名冲突：默认逐文件红标；开启"自动加序号"后消解。
- 规则未命中任何文件：提示"该规则对当前文件无影响"。
- Web 态无法改本地盘文件：明示能力边界，仅提供结果导出。

## 九、不做的事

- 不做在线云文件（无联网）。
- 不做正则作为默认必填门槛（高阶折叠）。
- 不做跨文件内容查找替换（仅文件名）。
- 不做权限/ACL 等系统级能力。
