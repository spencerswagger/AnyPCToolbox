# 产品方案：汉字拼音转换（百家姓优化）

> 状态：设计稿（未实现） · 日期：2026-08-22 · 模式：纯前端离线

## 一、定位

通用汉字拼音转换工具 + **复姓优先优化**。通用开源拼音库对**复姓**（欧阳、令狐、司马）会按单字拆分导致错音（"欧阳"应作 `ōu yáng` 整读），本项目内置《百家姓》姓氏表，切分时**先整词匹配复姓，再退到单字拼音**，显著提升与人名/称呼相关文本的准确率。姓部分高亮区分。

## 二、目标用户

- 需要给姓名 / 人名列表标注拼音的运营、HR、编辑。
- 需要拼音首字母做排序 / 索引 / 简码的开发者与办公用户。

## 三、页面布局

```
┌─────────────────────────────────────────────────────────────┐
│ ← 返回 | 汉字拼音转换                                         │
├─────────────────────────────────────────────────────────────┤
│  输入区（多行 textarea） → [转换]                              │
│  模式: [有声调] [无声调] [首字母]  · 粒度: [逐字] [整句] (单选组)│
├─────────────────────────────────────────────────────────────┤
│  预览（左右对照）                                              │
│   原文   │ 欧阳 令狐冲 王小明                                   │
│   拼音   │ Ōuyáng Lìnghú Chōng Wáng Xiǎoming                  │
│   姓高亮：欧阳/令狐/王 标色                                     │
├─────────────────────────────────────────────────────────────┤
│  (折叠) 姓氏表查看 & 自定义增补                               │
└─────────────────────────────────────────────────────────────┘
```

- 原文与拼音列表同步行滚动（`md:grid-cols-2`，移动端并排堆叠）。
- 输出可整体复制、逐行复制、导出 `.txt`。

## 四、交互流程

1. 输入一行或多行文本。
2. 选模式（有声调/无声调/首字母）与粒度（逐字/整句），实时重算并高亮姓部分。
3. 粘贴多行姓名时，每行独立输出一行拼音，便于直接复制为通讯录/表格列。
4. 可查看内置姓氏表，并支持"自定义增补姓氏/复姓"（存本地），使专有家族姓氏不误读。

## 五、功能详述

- **输出模式**：
  - 有声调：`其中` → `qí zhōng`（基础库默认，数字或符号声调可选样式）。
  - 无声调：`qizhong`。
  - 首字母：`qz`（可大小写）。
- **粒度**：逐字（每字后跟拼音）/ 整句（连读，不逐字断）。
- **百家姓优化**：内置 `src/data/surnames.json`（百家姓单姓 + 常见复姓如 欧阳/司马/诸葛/上官/令狐/独孤/公孙/南宫/司徒/轩辕...），切分时**先整词匹配姓氏表（尤其复姓优先）**，命中的姓氏部分按完整姓氏读音并高亮，其余文本交给通用拼音库。
- **自定义姓氏**：用户增补的条目存入 localStorage（key: `pinyin:surnames`），合并进切分匹配表。

## 六、数据与状态

- 内置姓氏表打包进 `src/data/surnames.json`（含 `_source`/`_updatedAt` 元字段）。
- 用户自定义姓氏存 localStorage。
- 输入文本不持久化。

## 七、技术要点与模块划分

```
src/lib/pinyin/
  convert.ts       # 主流程：先用姓氏表整词切分 + 高亮，再 fallback 到拼音库
  surname.ts       # 内置+自定义姓氏表加载/合并/匹配（复姓优先）
src/data/surnames.json   # 百家姓快照（含 _source/_updatedAt）
src/views/Pinyin.vue
```

- 方案选择：基于开源库（候选 `pinyin-pro` 或 `pinyin`）。前者内置 toneType 与 polyphone 处理，优先选用；若体积大引入成本高，退化为纯 `pinyin` + 自写声调样式。
- 姓氏切分逻辑独立成纯函数，可单测（给定 复姓用例断言不误拆）。

## 八、边界情况

- 同名文本含标点、数字、英文：只对中文字符注音，其余原样保留。
- 多音字（如 行/乐/重）：默认按常用读音，提供"整字多音选择"的折叠交互（点击某字可切换读音）——高阶项。
- 复姓出现在句中而非开头：仍保证整词匹配（如"他是欧阳先生"的"欧阳"不拆）。
- 生僻字不在库：原样保留 + 提示"未收录"。

## 九、不做的事

- 不做语音朗读 / TTS。
- 不做繁体 ⭢ 简体转换（仅拼音）。
- 不做句子级语义分词（聚焦字/词级拼音）。
- 不做语音词典级多音消歧（用常用音 + 手动切换）。
