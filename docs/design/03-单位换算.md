# 产品方案：单位换算（文本自动识别 + 全量等价）

> 状态：设计稿（未实现） · 日期：2026-08-22 · 模式：纯前端离线

## 一、定位

用户输入 `30kg`、`$1.99`、`2h`、`5'9"` 这类**自然文本片段**，工具自动识别出数值与数值前后的单位/货币符号，并一次列出该量纲下的**全部等价项**。用户**不需要**先在几十种单位体系里选择目标单位再输入——这是与传统换算工具最大的差异。

## 二、目标用户

- 需要快速换算长度/重量/存储/温度/面积/体积的普通办公用户。
- 涉及美元/人民币等币种汇率换算的用户。

## 三、页面布局

```
┌─────────────────────────────────────────────────────────────┐
│ ← 返回 | 单位换算                                             │
├─────────────────────────────────────────────────────────────┤
│  输入区（单行）：  [30kg 和 $1.99        ]  [换算]            │
│  提示：支持多个片段，如"30kg 和 $1.99"                         │
├─────────────────────────────────────────────────────────────┤
│  结果区（按片段分组）                                          │
│   [片段: 30 kg]                                               │
│   ├ 长度: 30 kg = 30,000 g · 66.14 lb · 1,058.2 oz ...        │
│   └ 重量(...)                                                 │
│   [片段: 1.99 美元]                                            │
│   └ 汇率: 1.99 US$ ≈ 14.3 CNY（汇率 7.18 @2026-08-20）         │
├─────────────────────────────────────────────────────────────┤
│  (折叠) 手动单位选择表格 -- 正统选单位式换算备用                  │
└─────────────────────────────────────────────────────────────┘
```

- 结果按"片段"分卡片；每卡片先列"最可能的量纲"，再列所有等价项，每项末尾 `[复制]`。
- 底部状态栏：`汇率/密度数据更新至 <快照日期>`（无在线字样），对齐身份证号工具先例。

## 四、交互流程

1. 输入一段文本（可含多个片段），点 `换算` 或回车。
2. 词法切分：提取每个 `数值 + 单位` 片段，识别出数值、单位词、货币符号、量纲。
3. 无法识别单位的部分：灰显并提示"无法识别片段：xxx"。
4. 识别成功的片段分组渲染全量等价项，可复制。
5. "手动选择单位"作为折叠收益项保留，满足想精确指定目标单位的场景。

## 五、识别能力 / 量纲覆盖

- **数值**：整数、小数、负号、千分位（`1,000`）、科学计数（`1e3`）、分数（`1/2`）、带前后单位（`30kg`、`$1.99`、`2in`、`5'9"` 英寸-英尺）。
- **量纲**：
  - 长度：m/cm/mm/km/in/ft/yd/mi/里/尺/寸 ...
  - 重量 / 质量：kg/g/mg/t/lb/oz/斤/两/磅 ...
  - 数据量：B/KB/MB/GB/TB ...
  - 温度：℃/℉/K（需换算公式而非倍率）
  - 面积：㎡/㎡/ha/亩/亩 ...
  - 体积 / 容量：L/mL/m³/gal ...
  - 时间：s/min/h/day/week ... （扩展到持续时间换算）
  - 货币：US$、CN¥、€、£、¥（需汇率快照）
- **单位词缀**：千/兆/吉/太（k/M/G/T）自动覆盖。

## 六、数据与状态

- **汇率用内置快照数据**（打包进 `src/data/rates.json`，含 `_source`/`_updatedAt` 元字段），更新 = 手动重新下载覆盖该文件，不做在线拉取。
- 手动选择模式选择的目标单位偏好可存 localStorage（key: `units:pref`）。
- 输入文本不持久化（隐私）。

## 七、技术要点与模块划分

```
src/lib/units/
  lexer.ts        # 数值+单位 词法切分（数字、正负、分数、千分位、前后单位）
  registry.ts     # 单位词缀库：别名->{canonical, factor, dim, symbol}
  convert.ts      # 量纲内 单值 -> 全部等价项；温度/汇率特殊处理
  money.ts        # 货币符号识别 + 快照汇率换算
src/data/rates.json  # 汇率 & 一些常量密度快照（含 _source/_updatedAt）
src/views/Units.vue
```

- 词法层是难点：`30kg` vs `$1.99` vs `5'9"` 的前置符号、后置单位、复合符号要统一建模。

## 八、边界情况

- 无单位纯数字：提示"未识别到单位"。
- 单位歧义（如 `m` 可作 meters/分钟）：按上下文 + 预置权重选最可能量纲，并允许用户改量纲。
- 汇率无快照的币种：标注"无汇率数据"，仅做货币符号识别。
- 温度等非线性换算：用公式而非倍率，结果标注"基于公式换算"。
- 超大数值/极端小数值：科学计数显示。

## 九、不做的事

- 不做在线汇率拉取 / 实时行情。
- 不做任意字符串语义理解（仅数值+单位）。
- 不做面积/体积单位之外的高阶物理量（如压力、能量），首版聚焦 8 种常见量纲。
