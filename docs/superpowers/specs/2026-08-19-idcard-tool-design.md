# 身份证号工具设计

日期：2026-08-19
状态：已确认

## 目标

在工具箱中新增「身份证号工具」（路由 `/idcard`），支持：

- 身份证号校验位校验（列表行内绿/红标签）
- 发证地查询（省 + 市 + 区县）
- 出生日期、性别、年龄（周岁）提取
- 批量生成（数量/性别/年龄段/地区均可选，不填则随机）
- 单个复制、全部复制
- 15 位老身份证号自动转 18 位
- 号码列表跨启动保留（localStorage），可清空

## 数据策略（用户修订版）

**不做运行时在线拉取，数据打包在项目文件中。**

- `src/data/china.json`：区划码数据快照（开发时从 https://github.com/mumuy/idcard （MIT 许可，数据源即 passer-by.com）抓取转换，约 2400 条，格式 `{ "110000": "北京市", ... }`）。
- 文件头含元字段：`_source`（数据来源 URL）、`_updatedAt`（快照日期）。
- 状态栏显示：`📦 内置区划数据 · <快照日期>`，不显示在线/离线状态（无网络行为）。
- 更新数据 = 开发者重新下载覆盖该文件（来源 URL 记录在 `_source`）。

## 文件结构

```
src/
  lib/idcard.ts          # 纯函数：校验、解析、15转18、批量生成
  lib/areaData.ts        # 加载 china.json，提供 getAreaName(code) / 级联选项
  data/china.json        # 内置区划数据（含 _source/_updatedAt）
  views/IdCard.vue       # 页面
```

路由注册到 `src/router/index.ts`，首页 `Home.vue` 增加工具卡片。

## 核心算法（src/lib/idcard.ts）

- **校验位**：ISO 7064:1983.MOD 11-2。权重 `[7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2]`，余数映射 `['1','0','X','9','8','7','6','5','4','3','2']`。
- **15 → 18 位**：出生年前补 `19`，末尾按校验位算法补算。
- **解析**：
  - 地址码 6 位 → 省（`XX0000`）/市（`XXXX00`）/区县逐级查名；
  - 直辖市（11/12/31/50）只拼 省 + 区县；`XX90XX`（省直辖县级）与港澳台（81/82/83）按开源库规则拼接；
  - 出生日期：7-14 位，需为合法日期；性别：第 17 位奇男偶女；年龄：生日到今天的周岁。
- **解析结果类型** `IdInfo`：`{ valid, reason?, type, sign, birthday, sex, age }`；`reason` 枚举：格式错误 / 长度错误 / 非法日期 / 校验位错误 / 未知区划 / 暂不支持（93 开头外国人永居证等）。
- **批量生成 `generate(options)`**：options 全可选 `{ count=10, sex?, minAge?, maxAge?, areaCode? }`；从候选地址码中随机取码、按年龄段反推合法出生日期、顺序码按性别奇偶随机、校验位按算法补算——生成结果保证校验通过。
  - 候选地址码规则：china.json 中能解析出名称的 6 位码，排除末两位为 `00` 的省市占位码、名称为「市辖区/县」的占位码、港澳台（81/82/83 开头）；若指定了 `areaCode` 则限定该省/市/区县范围内随机。

## 数据模型

```ts
interface IdEntry {
  id: string        // 18 位号码（15 位输入已转换）
  original: string  // 原始输入（与 id 不同时保留展示）
  addedAt: number
}
```

- localStorage key `idcard:list`，JSON 数组，重启保留；「清空列表」按钮整表清除。
- 去重：按 `original` 归一化（去空格）判重，重复提交直接选中已存在项。

## 页面布局与交互（遵循 docs/superpowers/specs/2026-08-18-tool-dev-convention.md）

1. **顶栏**：`← 返回 | 身份证号工具 |` 右侧次操作按钮：`全部复制`、`清空列表`。
2. **输入区**（居中卡片）：多行 textarea + 主按钮`确认`；Enter 提交（Shift+Enter 换行）；`批量生成` 次按钮展开配置行（数量/性别/年龄段/省市区级联下拉，均可留空随机），配置行内主按钮`生成`。
3. **主区** `grid md:grid-cols-[1fr,1.2fr]`，移动端堆叠：
   - **左：号码列表**（菜单栏风格，选中行 `bg-accent`）：每行 = 号码（15 位输入附 `15位→18位` 角标）+ 校验结果标签（绿 `✓ 通过` / 红 `✗ 不通过`）+ 悬停显示复制图标按钮；点击行选中。
   - **右：信息预览卡片**：发证地 / 出生日期 / 性别 / 年龄 / 号码类型 字段表；无效号码顶部显示红色横幅（原因）。
4. **底部状态栏**：左 `📦 内置区划数据 · 2026-08-19`；右 `共 N · 有效 N · 无效 N`；复制成功等操作反馈短暂显示在此。

## 行为细节

- 提交：按行拆分、trim、去空行、去重；全部入列表后选中**本次输入的第一个**。
- 格式非法的行同样入列表（红标），预览显示具体原因；列表滚动区最大高度固定，超长滚动。
- 复制：`navigator.clipboard.writeText` + try/catch；全部复制以换行分隔；成功后状态栏反馈 `已复制 N 条`。

## 样式

只用语义 token（`bg-card` / `bg-accent` / `text-destructive` 等）；通过标签绿/红用 `bg-emerald-500/15 text-emerald-600 dark:text-emerald-400` 与 `bg-destructive/15 text-destructive` 类语义色（暗色模式随 token 生效）；交互元素带 `focus-visible:ring-2`。

## 边界情况

- 15 位输入：转换后参与校验与解析，预览注明「由 15 位升位」。
- 未知区划码：红标，原因为「未知区划」，仍尽量展示出生日期等其余字段。
- 出生日期非法（如 2 月 30 日）：红标，原因「非法日期」。
- 93 开头外国人永居证：红标，原因「暂不支持」。
- 空提交 / 仅空白行：忽略，无操作。
- localStorage 解析失败：忽略并重置为空列表。
