设计要点

  • 1 响应式网格 — 卡片使用 CSS Grid 自动换行（minmax(240px, 1fr)），适配桌面到 Web 不同分辨率
  • 2 卡片交互 — 悬停时浮现阴影（shadow-lg）+ 蓝色边框高亮，点击跳转对应工具页
  • 3 顶部导航栏 — Logo 区域 + 亮暗主题切换开关，所有页面统一
  • 4 亮暗双主题 — 使用 shadcn/ui CSS 变量驱动，所有组件自动适配
  • 5 可扩展架构 — 预留"更多工具"占位卡片，后续只需添加新卡片路由即可
