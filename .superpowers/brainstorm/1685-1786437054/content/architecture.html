AnyPCToolbox — 整体架构

Tauri 2.x + Vite + Vue3 + shadcn/ui，一套代码覆盖桌面和 Web

系统架构

桌面端 (Tauri)
Rust 后端 (src-tauri/)
文件系统 · 系统API · 原生窗口
系统 WebView
WKWebView / WebView2 / WebKitGTK
Vue3 前端 (Vite 构建)
shadcn/ui · 离线运行
Web 端
Vite 构建产物
纯静态文件部署
Vue3 前端 (同一套代码)
shadcn/ui · 浏览器运行

项目结构

anypctoolbox/
├── src-tauri/ # Rust 后端 (Tauri)
│ ├── src/main.rs # 系统命令注册
│ └── Cargo.toml
├── src/ # Vue3 前端源码
│ ├── App.vue
│ ├── router/ # 路由配置
│ ├── views/ # 页面组件
│ │ ├── Home.vue # 主页 - 工具卡片
│ │ ├── Markdown.vue # Markdown 工具
│ │ └── Json.vue # JSON 工具
│ ├── components/ # 通用组件
│ ├── lib/ # 工具逻辑层
│ └── assets/ # 静态资源
├── package.json
└── vite.config.ts
