自己动手查一下，通常更准

照着下面你自己的系统来做，一分钟就能找到。

1.打开「终端」，任选一种方式就行： 方式一（最快）：同时按下键盘上的 Ctrl + Alt + T 三个键。 方式二：在桌面空白处点右键，在菜单里选「在终端中打开」。 方式三：打开系统的应用菜单（所有程序的列表），在搜索框搜“终端”或“Terminal”再点开。应用菜单的位置各系统不同，通常在屏幕角落的图标里。 终端就是那个黑色小窗口样的程序。
2.在窗口里输入 uname -m，然后按回车。 注意：uname 和 -m 之间要留一个空格，输入完一定要按回车键。
3.看输出的一行字母： 显示 x86_64：芯片架构是 amd64。 显示 aarch64：芯片架构是 arm64。
1.进入能看到「系统类型」的页面： Windows 11：点屏幕正中下方的「开始」按钮 ，再点「设置」，然后「系统」-「关于」。 Windows 10：点屏幕左下角的「开始」按钮 ，再点「设置」，然后「系统」-「关于」。 Windows 8：把鼠标移到屏幕最右边滑出侧边栏，点「设置」，然后「电脑和设备」-「电脑信息」。 Windows 7 / XP：在桌面上右键点「我的电脑」或「计算机」，选「属性」。
2.找到写着「系统类型」的一行，看写的是什么： 写的是「x64 处理器」：芯片架构是 amd64。 写的是「ARM64」：芯片架构是 arm64。 写的是「x86」或什么都没标：芯片架构是 x86（32 位）。
1.点屏幕最左上角的苹果标志。
2.点「本机」（也叫“关于本机”）。
3.看「芯片」或「处理器」那一行： 如果写的是「Apple M1 / M2 / M3 / M4」这样的：芯片架构是 arm64。 如果写的是「Intel」：芯片架构是 amd64。
